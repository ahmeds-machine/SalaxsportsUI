# Salaxsports UI ⚽️

The frontend user interface for a comprehensive sports venue booking and video clip recording platform. This repository contains the static HTML, CSS, and JavaScript files that make up the salax sports ui and user profiles.

## 🚀 Features

* **Venue Booking (Turf Fields):** Interfaces for browsing, selecting, and reserving sports fields.
* **Player Profiles:** Dedicated views for individual player statistics and information.
* **Video Clip Management:** Includes the "Goal of the Week" module and media galleries for match recordings.
* **Admin & Analytics:** Revenue analytics and centralized dashboard views for management.

## 🛠️ Technology Stack

* **Structure:** HTML5
* **Logic:** Vanilla JavaScript
* **Integration Readiness:** Designed to be served and integrated with a NestJS backend infrastructure.
